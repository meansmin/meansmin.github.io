개인정보 처리방침

앱에서 직접 삭제하기 (가장 빠름)

앱을 사용할 수 있다면 아래 순서로 즉시 삭제할 수 있습니다.

  1. 내 발 지도 앱을 실행하고 로그인합니다.
  2. 오른쪽 위 ⋮ 버튼 → 설정을 누릅니다.
  3. 맨 아래 계정 삭제를 누릅니다.
  4. 확인 창에 삭제 라고 직접 입력하면 계정과 모든 데이터가 삭제됩니다.
    이메일로 가입한 계정은 안전을 위해 비밀번호를 한 번 더 확인합니다. 구글 계정으로 로그인한 경우에는 비밀번호를 묻지 않습니다.

이메일로 삭제 요청하기

앱에 로그인할 수 없거나 앱을 이미 지운 경우, 아래 주소로 요청해 주세요. 본인 확인 후 영업일 기준 7일 이내에 처리하고 회신드립니다.

삭제되는 데이터

계정을 삭제하면 아래 정보가 모두 영구 삭제되며 복구할 수 없습니다.

  • 계정 정보 — 이메일 주소, 비밀번호, 닉네임
  • 업로드한 사진 전체 (저장소 원본 포함)
  • 사진에 남긴 메모
  • 방문 지역 기록과 지도에 찍힌 발도장

보관되는 데이터

삭제 후 따로 보관하는 개인정보는 없습니다. 다만 관계 법령에서 보존을 요구하는 경우에 한해 해당 기간 동안만 보관한 뒤 파기합니다.

처리 기간

  • 앱에서 직접 삭제 — 즉시 처리됩니다.
